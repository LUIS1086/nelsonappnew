# Checklist de pruebas en celular real (v3.9.0)
Marca cada punto en **Android (APK)** y **iPhone/Chrome**, en tema claro y oscuro:
- [ ] Primer arranque: splash ~1,3 s, ícono de llaves, nombre y lema correctos
- [ ] Cerrar y reabrir: splash corto; tocar el splash lo salta
- [ ] PIN y huella funcionan después del splash
- [ ] Órdenes: crear, cambiar estado, avisar por WhatsApp
- [ ] Caja: venta con ticket, WhatsApp/PDF/imagen
- [ ] Cartera y Garantías
- [ ] Configuración → Datos del negocio: guardar nombre, lema y línea superior; recargar y verlos en el splash
- [ ] Configuración → Almacenamiento → Archivar órdenes viejas (haz respaldo en Drive antes; prueba con +24 meses)
- [ ] Celular en horizontal y tablet
- [ ] Actualización: aparece el aviso "nueva versión" y se instala sin perder datos
- [ ] Instalación limpia (otro celular): sale el asistente "Configura tu negocio"
